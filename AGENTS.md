# TalkBuddy project instructions

- Build one approved phase at a time. Do not begin the next phase without user approval.
- Keep the backend modular and use environment variables for configuration and secrets.
- Add focused tests for important backend behavior and run them before reporting completion.
- Phase 8 builds the React frontend in `frontend/` using existing backend contracts. Keep session tokens out of browser storage, send same-origin credentials and CSRF headers, and encode complete PCM WAV chunks for WebSockets. Do not alter backend APIs unless necessary.
